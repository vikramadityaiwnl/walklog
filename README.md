# walklog

walklog is an offline-first mobile app for documenting site walkthroughs and organizing construction and property inspection issues. It helps people capture notes and photos on site, turn observations into structured punch lists, and prepare reports for clients.

The app uses Firebase as its backend and Firebase AI Logic for both on-device and cloud AI, supporting offline note structuring and cloud-assisted issue review.

Setup and development instructions will be added as the app is completed.
